# CloudTasks

Aplicacion web de gestion de tareas. Construida con HTML, CSS y JavaScript vanilla,
persistencia en Supabase (PostgreSQL), desplegada en Vercel y expuesta mediante
Cloudflare (DNS + HTTPS).

## Estructura
- `index.html` - vista principal
- `css/styles.css` - estilos
- `js/app.js` - logica CRUD y conexion con Supabase

## Flujo de ramas
main $\leftarrow$ develop $\leftarrow$ features/*
